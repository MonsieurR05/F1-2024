# F1 2024 Season Data Explorer
## 5-Week Group Project Plan
**Team Members:** Rahul and Rhett

---

### Week 1 – Planning and Setup

#### Meeting Summary
Rahul and Rhett discussed key features to implement and agreed on the overall structure of the site. They outlined the core pages: Drivers, Teams, Circuits, Races, and Standings. A database schema with seven tables was designed to store F1 statistics. The team selected Astro and React for layout and divided initial responsibilities.

#### Goals
- Develop initial site layout concepts
- Finalise database schema
- Set up foundational backend and frontend folders

#### Assigned Tasks
- **Rahul:** Begin database setup and Flask backend initialisation
- **Rhett:** Start building frontend pages and establishing layout structure

---

### Week 2 – Backend and Data Integration

#### Meeting Summary
Rahul completed the Flask API and database integration. Rhett explored frontend connectivity to the backend. Both worked on connecting to the Ergast API for real-time F1 data and aligned on the data flow architecture.

#### Goals
- Operational Flask backend with test data
- API routes ready for frontend consumption
- Initial connection established to the Ergast API

#### Assigned Tasks
- **Rahul:** Complete data models and implement error handling
- **Rhett:** Develop React components prepared to receive API data

---

### Week 3 – Frontend Development

#### Meeting Summary
Rahul focused on building user interfaces for Drivers, Circuits, and Standings. Rhett integrated dynamic data into these pages. They collaborated on chart visualisations and discussed how to present race data.

#### Goals
- Functional pages displaying real-time F1 information
- Search bar implemented for drivers or races
- Display of first circuit map or stat chart

#### Assigned Tasks
- **Rhett:** Refine UI design and add interactive features
- **Rahul:** Connect API data to visual elements (charts and maps)

---

### Week 4 – Feature Completion

#### Meeting Summary
The team reviewed each feature for completeness. Enhancements such as sortable tables, in-depth stats, and updated standings were implemented. Performance and aesthetics were also evaluated.

#### Goals
- Ensure all pages operate with full data integration
- Add advanced search and filter functionality
- Include live stats and circuit visualisations

#### Assigned Tasks
- **Rahul:** Final backend testing with live data
- **Rhett:** Finalise design elements and address missing components

---

### Week 5 – Final Testing

#### Meeting Summary
Rahul and Rhett performed a comprehensive final review, resolving bugs and styling inconsistencies.

#### Goals
